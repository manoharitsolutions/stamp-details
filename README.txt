STAMP DETAILS — iPhone & Android PWA

This package turns the web assets embedded in the supplied Android APK into an installable Progressive Web App.

IMPORTANT:
- This ZIP is the website/PWA source, not an iOS IPA or App Store upload.
- To install on iPhone, host the files on an HTTPS website first.
- On iPhone: open the HTTPS URL in Safari > Share > Add to Home Screen > Add.
- On Android: open the HTTPS URL in Chrome > menu > Install app / Add to Home screen.
- WhatsApp opens with a draft for review; the user must press Send manually.
- User-entered fields are stored in the browser's localStorage on that device.
